# LINGYUN.Abp.Serilog.Enrichers.UniqueId

Simplified Chinese | [English](./README.EN.md)

Add a unique identifier to the log attribute and use the snowflake algorithm to generate a unique ID.

## Features

* Add a unique identifier to each log event
* Generate distributed unique ID based on Snowflake algorithm
* Support custom snowflake algorithm configuration
* Supports both code configuration and JSON configuration
* Seamless integration with Serilog

## Module reference

```csharp
[DependsOn(typeof(AbpSerilogEnrichersUniqueIdModule))]
public class YouProjectModule : AbpModule
{
  // other
}
```

## Configuration items

### Constant configuration

* AbpSerilogUniqueIdConsts.UniqueIdPropertyName - the name of the unique identification field, the default is "UniqueId"

### Snowflake algorithm configuration

Configure snowflake algorithm parameters through `AbpSerilogEnrichersUniqueIdOptions`:

```json
{
  "UniqueId": {
    "Snowflake": {
      "WorkerId": 1, // Worker machine ID
      "DatacenterId": 1, // Data center ID
      "Sequence": 0, // sequence number
      "BaseTime": "2020-01-01 00:00:00" // Base time
    }
  }
}
```

## How to use

### Code configuration method

```csharp
Log.Logger = new LoggerConfiguration()
    .Enrich.WithUniqueId()
    // ...other configurations...
    .CreateLogger();
```

### JSON configuration method

```json
{
   "Serilog": {
    "MinimumLevel": {
      "Default": "Information"
    },
    "Enrich": [ "WithUniqueId" ]
  }
}
```

## Implementation details

This enricher uses the snowflake algorithm to generate a unique ID for each log event. The characteristics of the snowflake algorithm are:

* The generated ID is a 64-bit long integer
* ID consists of timestamp, data center ID, worker machine ID and serial number
* Ensure uniqueness in a distributed environment
* Order based on timestamp

## Best Practices

1. Properly configure the work machine ID and data center ID to avoid conflicts in a distributed environment:
```json
{
  "UniqueId": {
    "Snowflake": {
      "WorkerId": 1,
      "DatacenterId": 1
    }
  }
}
```

2. Set an appropriate base time to maximize the available time range of the ID:
```json
{
  "UniqueId": {
    "Snowflake": {
      "BaseTime": "2020-01-01 00:00:00"
    }
  }
}
```

3. You can use the UniqueId field for precise positioning when querying logs.

## Notes

1. The ID generated by the snowflake algorithm has an increasing trend, but it is not guaranteed to be strictly incremental.
2. The worker machine ID and data center ID must be unique in the cluster
3. Once the base time is set, it cannot be modified, otherwise it may cause ID duplication.
4. Each log event will generate a new unique ID, which may add some performance overhead
