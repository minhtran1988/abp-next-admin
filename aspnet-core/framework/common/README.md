# common module overview

## Module introduction
The `common` module is the basic module of the ABP framework, providing a series of common functions and services designed to support the development and expansion of various applications. This module contains multiple sub-modules, each of which implements specific functions to help developers quickly build efficient applications.

## List of included items
1. **LINGYUN.Abp.Aliyun.Authorization**
   - Provides Alibaba Cloud basic authentication functions and supports the configuration of AppKeyId and AccessKeySecret.

2. **LINGYUN.Abp.AspNetCore.HttpOverrides**
   - Implemented the rewriting of HTTP transport headers to support obtaining the real client address in the reverse proxy.

3. **LINGYUN.Abp.AspNetCore.Mvc.Client**
   - Provide configurable user configuration cache time and support multi-tenant interface.

4. **LINGYUN.Abp.BackgroundJobs.Hangfire**
   - Background job module implemented based on Hangfire, supporting immediate, delayed and periodic tasks.

5. **LINGYUN.Abp.ExceptionHandling**
   - Provides a unified exception handling and notification mechanism, and supports custom exception handlers.

6. **LINGYUN.Abp.Location**
   - Provides geocoding, reverse geocoding and IP geographical location analysis functions.

7. **LINGYUN.Abp.IdGenerator**
   - Implement distributed unique ID generator and support snowflake algorithm.

8. **LINGYUN.Abp.Wrapper**
   - Unified packaging of API return results and exception handling.

## Overview of the main features of each project
- **Alibaba Cloud Authentication Module**: Provides Alibaba Cloud's authentication function, simplifying access to Alibaba Cloud services.
- **HTTP rewrite module**: Process the headers in HTTP requests to ensure that the real client address is obtained.
- **MVC client module**: Provides user configuration caching and supports multi-tenant architecture.
- **Background job module**: Supports task scheduling and execution to ensure the reliability of background tasks.
- **Exception handling module**: handles exceptions in applications and provides a unified notification mechanism.
- **Location Service Module**: Provides geographical location-related functions and supports conversion between addresses and coordinates.
- **ID generation module**: Generate distributed unique IDs to ensure uniqueness in high-concurrency environments.
- **Wrapper module**: Unified processing of API return results and exceptions to improve API usability.

## Overall purpose and importance of the module
The `common` module provides infrastructure for the ABP framework, allowing developers to quickly integrate common functions when building applications, reduce duplication of work, and improve development efficiency. Through these modules, developers can focus more on the implementation of business logic without worrying about the underlying implementation details.

## A brief description of how to use or integrate this module
