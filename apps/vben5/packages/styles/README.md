# @vben/styles

A common style file for multiple `app`, inheriting all the capabilities of `@vben-core/design`. There are common style files in business that can be placed here.

## Usage

### Add dependencies

```bash
# Enter the target application directory, such as apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/styles
```

### Use

```ts
import '@vben/styles';
```
