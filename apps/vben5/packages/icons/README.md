# @vben/icons

Icon file common to multiple `app`, inheriting all capabilities of `@vben-core/icons`. There are common icons in the business that can be placed here.

## Usage

### Add dependencies

```bash
# Enter the target application directory, such as apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/icons
```

### Use

```ts
import { X } from '@vben/icons';
```
