# @vben/constants

Constants common to multiple `app` inherit all capabilities of `@vben-core/shared/constants`. There are common constants in business that can be placed here.

## Usage

### Add dependencies

```bash
# Enter the target application directory, such as apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/constants
```

### Use

```ts
import { LOGIN_PATH } from '@vben/constants';
```
