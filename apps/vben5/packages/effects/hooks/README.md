# @vben/hooks

A hook common to multiple `app`, inheriting all the capabilities of `@vben/hooks`. There are common hooks in the business that can be placed here.

## Usage

### Add dependencies

```bash
# Enter the target application directory, such as apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/hooks
```

### Use

```ts
import { useNamespace } from '@vben/hooks';
```
