# @vben/types

Tool type common to multiple `app`, inheriting all capabilities of `@vben-core/typings`. Common type definitions in business can be placed here.

## Usage

### Add dependencies

```bash
# Enter the target application directory, such as apps/xxxx-app
# cd apps/xxxx-app
pnpm add @vben/types
```

### Use

```ts
// It is recommended to add type
import type { SelectOption } from '@vben/types';
```
